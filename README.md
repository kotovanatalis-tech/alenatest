# Тест «Готовы ли вы к международному собесу?» — Telegram-бот + Mini App

В архиве две части:

| Папка | Что это |
|---|---|
| `webapp/index.html` | Ваш тест в виде **Telegram Mini App** — тот же дизайн, плюс вибрация при нажатии, цвет шапки под тему, кнопка CTA открывает ссылку внутри Telegram, «Пройти заново» без перезагрузки |
| `bot/` | **Бот** на Python (aiogram 3): на `/start` предлагает открыть приложение или пройти тест прямо в чате кнопками. Результат считается по тем же правилам, что и в веб-версии |

---

## Шаг 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумайте имя и username (должен заканчиваться на `bot`)
3. Скопируйте **токен** вида `123456789:AA...`

## Шаг 2. Выложить Mini App в интернет

Telegram открывает только страницы по **https**. Проще всего бесплатно:

**Вариант А — Netlify Drop (1 минута, без регистрации в коде)**
1. Зайдите на https://app.netlify.com/drop
2. Перетащите туда папку `webapp`
3. Получите адрес вида `https://xxx.netlify.app` — это ваш `WEBAPP_URL`

**Вариант Б — GitHub Pages**
1. Создайте репозиторий, загрузите в него `index.html`
2. Settings → Pages → Branch: `main` → Save
3. Адрес: `https://<ваш-логин>.github.io/<репозиторий>/`

> Перед загрузкой можно вписать ссылку для кнопки «Собрать мою дорожную карту» —
> в `index.html` найдите строку `const CTA_URL = '';` и вставьте ссылку
> (форма записи, Calendly, `https://t.me/ваш_ник` и т.п.).

**Сделать приложение «настоящим» Mini App (по желанию):** в @BotFather →
`/newapp` → выберите бота → укажите `WEBAPP_URL`. Получите прямую ссылку
вида `t.me/ваш_бот/test`, которую можно ставить в сторис, посты и био.

## Шаг 3. Запустить бота

Нужен Python 3.10+.

```bash
cd bot
pip install -r requirements.txt

export BOT_TOKEN="123456789:AA..."            # из шага 1
export WEBAPP_URL="https://xxx.netlify.app"   # из шага 2 (можно не указывать)
export CTA_URL="https://ссылка-на-запись"     # по желанию

python bot.py
```

На Windows вместо `export` используйте `set BOT_TOKEN=...`.

Готово — напишите боту `/start`. Если указан `WEBAPP_URL`, бот сам добавит
кнопку «Тест» слева от поля ввода сообщения.

### Команды бота
- `/start` — приветствие и выбор: приложение или тест в чате
- `/quiz` — сразу начать тест в чате

## Шаг 4. Чтобы бот работал круглосуточно

Пока `python bot.py` запущен у вас на компьютере — бот отвечает. Для работы 24/7
разместите папку `bot` на любом хостинге с Python:
**Railway**, **Render**, **PythonAnywhere** (есть бесплатный тариф) или любой VPS.
Переменные `BOT_TOKEN`, `WEBAPP_URL`, `CTA_URL` задаются в настройках хостинга,
команда запуска — `python bot.py`.

## Как менять тексты

- **В боте** — всё в `bot/quiz_data.py` (вопросы, баллы, тексты результатов, CTA)
- **В приложении** — в `webapp/index.html`, блок `<script>` (массивы `QUESTIONS`, `RESULTS`)

Правило оценки одинаковое: в каждом блоке 3 вопроса по 0–2 балла;
сумма ≤ 4 → «Подтянуть», иначе «ОК». Видео рекомендуется для самого слабого блока.
